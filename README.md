## Selected work

**[Ecuador Public Procurement Data Quality Monitor](https://github.com/Vladimirjon/ec-public-procurement-quality-monitor)**  
Auditable foundation for preserving and assessing public-procurement source data. The current implementation covers content-addressed raw storage, SHA-256 integrity checks, typed source access, PostgreSQL persistence, checksum-verified migrations, append-only audit rules, and automated tests.

`Python` `PostgreSQL` `httpx` `psycopg` `Docker`

> Status: in development. End-to-end ingestion and quality reporting are not complete yet.

**[Computer Vision Game Reconstruction](https://github.com/Vladimirjon/Captura_automatica_de_posiciones_con_AI_Vision)**  
Pipeline that detects pieces, corrects perspective, reconstructs an Amazons board, validates moves, and tracks match state. The YOLOv8-nano model reached 99.38% precision, 100% recall, and 99.50% mAP50 on the project evaluation.

`Python` `YOLOv8` `OpenCV`

**[Distributed Identity and High Availability](https://github.com/Vladimirjon/PasquelJ-MiniIdM)**  
Identity architecture across three Linux virtual machines using replicated OpenLDAP, redundant Kerberos, PKI/TLS, HAProxy, and Keepalived. Controlled failure tests maintained 12/12 successful requests.

`Linux` `OpenLDAP` `Kerberos` `HAProxy` `Keepalived`
